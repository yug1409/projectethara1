# 🍔 Food Order Management System

A full-stack Food Order Management Website built using the MERN Stack.

This application allows users to browse food items, add them to cart, place orders, and track their order status. It also includes an admin dashboard for managing food items and orders.

---

# 🚀 Tech Stack

## Frontend
- React.js
- React Router DOM
- Context API
- Axios
- Tailwind CSS
- Vite

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs
- Express Rate Limit

# ⚙️ Environment Variables

Create `.env` file inside backend folder:

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```

# 📦 Installation

## Clone Repository

```bash
git clone https://github.com/yug1409/food-order-management.git
```

---

# Backend Setup

```bash
cd backend

npm install

npm run dev
```

Backend runs on:

```plaintext
http://localhost:5000
```

---

# Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend runs on:

```plaintext
http://localhost:5173
```
